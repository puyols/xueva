# ✅ Чеклист развертывания Belka Flowers

Используйте этот чеклист при развертывании сайта на production сервере.

---

## 📋 Подготовка

- [ ] Скачан архив `belka-flowers-deploy.tar.gz`
- [ ] Есть доступ к серверу (SSH или FTP)
- [ ] Проверены требования (Node.js >= 14.0.0 или Apache 2.4+)
- [ ] Есть доменное имя или IP адрес

---

## 🚀 Развертывание

### Вариант A: Node.js

- [ ] Загружен архив на сервер
- [ ] Распакован: `tar -xzf belka-flowers-deploy-*.tar.gz`
- [ ] Перешли в директорию: `cd belka-flowers`
- [ ] Настроен порт в .env (если нужно): `echo "PORT=8080" > .env`
- [ ] Запущен сервер: `node server.js`
- [ ] Сервер доступен на порту 8080

### Вариант B: PM2 (с автозапуском)

- [ ] Установлен PM2: `npm install -g pm2`
- [ ] Запущен: `pm2 start ecosystem.config.js`
- [ ] Проверен статус: `pm2 status`
- [ ] Сохранен: `pm2 save`
- [ ] Настроен автозапуск: `pm2 startup`

### Вариант C: Apache

- [ ] Распакован архив в `/var/www/html` (или public_html)
- [ ] Включен mod_rewrite: `sudo a2enmod rewrite`
- [ ] Перезапущен Apache: `sudo systemctl restart apache2`
- [ ] Проверены права: `find . -type f -exec chmod 644 {} \;`
- [ ] Проверен .htaccess файл

---

## 🔧 Настройка

### Nginx (если используется как reverse proxy)

- [ ] Создан конфиг в `/etc/nginx/sites-available/`
- [ ] Добавлен proxy_pass на `http://localhost:8080`
- [ ] Создан симлинк в sites-enabled
- [ ] Проверена конфигурация: `nginx -t`
- [ ] Перезапущен Nginx: `systemctl restart nginx`

### SSL/HTTPS

- [ ] Установлен Certbot: `apt install certbot`
- [ ] Получен сертификат: `certbot --nginx -d your-domain.ru`
- [ ] Проверен автоматический renewal: `certbot renew --dry-run`
- [ ] Настроено перенаправление HTTP → HTTPS

### Firewall

- [ ] Открыт порт 80 (HTTP)
- [ ] Открыт порт 443 (HTTPS)
- [ ] Открыт порт приложения (если нужно, например 8080)

## 🆘 Troubleshooting

Если что-то не работает:

1. **Сервер не запускается**
   - Проверьте порт: `lsof -i :8080`
   - Проверьте логи: `pm2 logs` или `journalctl -xe`
   - Проверьте права: `ls -la`

2. **404 ошибки**
   - Проверьте .htaccess (Apache)
   - Проверьте nginx конфигурацию
   - Проверьте, что все файлы на месте

3. **Изображения не загружаются**
   - Проверьте директорию images/
   - Проверьте права: `chmod -R 755 images/`
   - Проверьте пути в HTML

4. **SSL не работает**
   - Перезапустите certbot
   - Проверьте конфигурацию nginx/apache
   - Проверьте firewall
