# Belka Flowers - Static Site

Статический экспорт интернет-магазина цветов Belka Flowers на базе Next.js.

## Описание

Это полностью статический сайт, включающий в себя:
- Предварительно отрендеренные HTML страницы
- Статические ресурсы Next.js (_next)
- Изображения и медиафайлы
- Node.js HTTP сервер для локальной разработки и хостинга

## Требования

- Node.js >= 14.0.0

## Установка и запуск

### Локально

```bash
# Установка зависимостей не требуется (нет внешних зависимостей)

# Запуск сервера
npm start
# или
node server.js

# Сервер будет доступен по адресу http://localhost:8080
```

### Переменные окружения

- `PORT` - порт для сервера (по умолчанию: 8080)

Пример:
```bash
PORT=3000 node server.js
```

## Развертывание

### 🚀 Быстрое развертывание (Рекомендуется)

Используйте готовый архив для развертывания:

```bash
# Создать архив
./pack-deploy.sh

# Архив будет создан: belka-flowers-deploy-YYYYMMDD_HHMMSS.tar.gz
```

Архив содержит все необходимое для развертывания на любом хостинге.
Подробнее: [QUICK-DEPLOY.md](QUICK-DEPLOY.md) или [README-PACK.md](README-PACK.md)

### На хостинге с Apache

1. Загрузите все файлы на хостинг
2. Убедитесь, что включен mod_rewrite в Apache
3. Файл `.htaccess` автоматически настроит правильную маршрутизацию

### На хостинге с Node.js

1. Загрузите все файлы на хостинг
2. Установите переменную окружения `PORT` (если требуется)
3. Запустите `npm start` или `node server.js`
4. Настройте процесс-менеджер (PM2, systemd) для автозапуска

#### Пример с PM2:

```bash
pm2 start server.js --name belka-flowers
pm2 save
pm2 startup
```

### На Vercel/Netlify

1. Загрузите репозиторий на GitHub
2. Подключите репозиторий к Vercel/Netlify
3. Настройки деплоя:
   - Build Command: (оставить пустым)
   - Output Directory: `.`
   - Install Command: (оставить пустым)

### Полная документация по развертыванию

См. [DEPLOYMENT.md](DEPLOYMENT.md) для подробных инструкций по всем вариантам развертывания
