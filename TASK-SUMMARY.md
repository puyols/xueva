
```bash

# Запустить
cd belka-flowers
node server.js
```

## 🎯 Варианты развертывания

Архив поддерживает несколько вариантов развертывания:

### 1. Node.js (Рекомендуется)
- Прямой запуск: `node server.js`
- Работает на порту 8080 (настраивается)
- Полный контроль над сервером

### 2. PM2 с автозапуском
- Автоматический перезапуск
- Мониторинг и логирование
- Готовая конфигурация included

### 3. Apache
- Статический хостинг
- .htaccess уже настроен
- Не требует Node.js

### 4. Nginx + Node.js
- Node.js как backend
- Nginx как reverse proxy
- Лучшая производительность

---

## 🔧 Требования

**Минимальные:**
- Место на диске: 2.5 GB
- Node.js >= 14.0.0 (для Node.js варианта)
- Apache 2.4+ с mod_rewrite (для Apache варианта)

**Рекомендуемые:**
- Node.js 18.x или 20.x
- PM2 для автозапуска
- Nginx как reverse proxy
- SSL сертификат (Let's Encrypt)
