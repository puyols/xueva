📦 ШАГ 1: СОЗДАТЬ АРХИВ ДЛЯ РАЗВЕРТЫВАНИЯ
═══════════════════════════════════════════════════════════════════

В терминале выполните:
  ./pack-deploy.sh

Будет создан файл: belka-flowers-deploy-YYYYMMDD_HHMMSS.tar.gz
Размер: ~2 GB (включает все изображения)


🚀 ШАГ 2: ЗАГРУЗИТЬ НА ХОСТИНГ
═══════════════════════════════════════════════════════════════════

Вариант A - Node.js хостинг (Рекомендуется):
  1. Загрузите архив на сервер
  2. Распакуйте: tar -xzf belka-flowers-deploy-*.tar.gz
  3. Перейдите в папку: cd belka-flowers
  4. Запустите: node server.js

Вариант B - Apache хостинг:
  1. Распакуйте архив локально
  2. Загрузите содержимое папки belka-flowers через FTP в public_html
  3. Готово! .htaccess уже настроен

Вариант C - Shared хостинг (Beget, Hostiman):
  1. Загрузите архив через панель управления
  2. Распакуйте в корневую директорию
  3. Если есть Node.js - запустите server.js
  4. Если только Apache - сайт уже работает


⚙️ ШАГ 3: НАСТРОЙКА (ОПЦИОНАЛЬНО)
═══════════════════════════════════════════════════════════════════

Изменить порт (по умолчанию 8080):
  echo "PORT=3000" > .env

Автозапуск с PM2:
  npm install -g pm2
  pm2 start ecosystem.config.js
  pm2 save
  pm2 startup

Настройка Nginx (если используется):
  sudo nano /etc/nginx/sites-available/default
  # Добавьте reverse proxy на http://localhost:8080

SSL сертификат (HTTPS):
  sudo certbot --nginx -d ваш-домен.ru
